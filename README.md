# Implantación de Aplicaciones Web — ASIR
### DIGITECHFP · Curso 2025–2026 · Alejandro Benítez Hidalgo

Tareas y prácticas del módulo de **Implantación de Aplicaciones Web** del ciclo formativo de Grado Superior en Administración de Sistemas Informáticos en Red (ASIR).

---

## RA1 — Introducción a JavaScript

| Tarea | Descripción |
|-------|-------------|
| **JavaScript I** | Primeros pasos con HTML y formato de texto básico |
| **JavaScript II** | Comprobación de números con estructuras condicionales |
| **Estructuras de control** | Lógica de control de flujo con `if / else if / else` |

---

## RA2 — Eventos y estructuras de datos

| Tarea | Descripción |
|-------|-------------|
| **Eventos** | Uso de `addEventListener` para capturar interacciones del usuario |
| **Eventos II** | Control de temperatura con lógica condicional y resultados dinámicos |
| **Arrays** | Manipulación de arrays en JavaScript |
| **Bucles y estructuras de control** | Generación de tablas numéricas con bucles |

---

## RA3 — Gestión de nodos del DOM

| Tarea | Descripción |
|-------|-------------|
| **Gestión de nodos I** | Creación y manipulación dinámica de nodos en el DOM con imágenes |
| **Gestión de nodos II** | Modificación de contenido con `innerHTML` y eventos |

---

## RA4 — Maquetación y aplicaciones web

| Tarea | Descripción |
|-------|-------------|
| **Maquetación web con nodos** | Página web de agencia de viajes generada dinámicamente con JavaScript |
| **Visor de imágenes II** | Galería de imágenes con navegación mediante flechas |

---

## RA5 — JSON y AJAX

| Tarea | Descripción |
|-------|-------------|
| **JSON, AJAX y JS** | Catálogo de coches cargado desde JSON con `fetch` y renderizado dinámico |
| **Eventos II (temperatura)** | Sistema de control de temperatura con validación y respuesta dinámica |

---

## RA6 — Clases, objetos y JSON

| Tarea | Descripción |
|-------|-------------|
| **Trabajo con clases II** | Catálogo de zapatillas generado dinámicamente a partir de un array de objetos |
| **JSON** | Diseño de un archivo JSON con datos de un estudiante: nombre, apellidos, edad, curso y asignaturas matriculadas |

---

## RA7 — JSON avanzado, AJAX y XML

| Tarea | Descripción |
|-------|-------------|
| **JSON II** | Catálogo de películas en formato JSON con título, año, género, duración y actores principales |
| **JSON, AJAX y JS** | Lectura de datos de vehículos desde un archivo JSON y renderizado dinámico en la página |
| **XML** | Documentos XML con lista de libros y catálogo de productos electrónicos con atributos y características |

---

## Tecnologías utilizadas

- HTML5 · CSS3 · JavaScript (ES6+)
- DOM API — `createElement`, `innerHTML`, `appendChild`
- Eventos — `addEventListener`
- AJAX — `fetch` + Promesas
- JSON · XML
- Clases y objetos en JavaScript
